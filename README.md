# ปัญหาซ้ำ สายงานขาย 1

รายงานสรุปปัญหาในงานของสายงานขาย 1 จากแบบฟอร์มทบทวนงานรายบุคคล 26 ชุด ใน 6 แผนก (ก.ย. 2569)

**เปิดอ่าน:** เปิด `index.html` ในเบราว์เซอร์ หรือดูผ่าน GitHub Pages ของ repo นี้

## ฉบับนี้เป็นฉบับเผยแพร่

แทนชื่อผู้กรอกทั้ง 26 คนด้วยตำแหน่งงาน — เนื้อหาปัญหา ตัวเลข และคำพูดทั้งหมดคงเดิม
ฉบับที่ระบุชื่อเก็บแยกไว้ใน repo private ไม่ได้อยู่ที่นี่

## ข้อจำกัดของข้อมูล

- ค่าเวลาและระดับ Impact เป็นค่าที่ผู้ปฏิบัติงานประเมินเอง ยังไม่ได้ทวนกับข้อมูลระบบ
- แผนกการตลาดออนไลน์มีผู้กรอกคนเดียว ยังไม่ควรสรุปเป็นภาพของทั้งแผนก
- ตัวเลขเป้าหมายในข้อเสนอเป็นข้อเสนอเพื่อให้หัวหน้าสายงานตัดสินใจ ไม่ใช่เป้าที่ตกลงแล้ว
